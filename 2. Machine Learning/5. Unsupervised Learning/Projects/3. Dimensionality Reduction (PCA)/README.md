# 📉 Dimensionality Reduction with PCA

Unsupervised feature projection and multi-dimensional variance retention using Principal Component Analysis (PCA).

---

## 📌 Project Overview
High-dimensional datasets introduce the curse of dimensionality, computational bottlenecks, and visualization challenges. This project implements:
- **Feature Standardization (`StandardScaler`)**: Normalizing multi-dimensional feature scales.
- **Principal Component Analysis (PCA)**: Computing covariance matrices, eigenvectors, and eigenvalues to project 5-dimensional cluster data onto the top 2 principal components (`PC1`, `PC2`).
- **2D Latent Cluster Visualization**: Visualizing cluster separation in lower-dimensional space using Seaborn scatterplots.
